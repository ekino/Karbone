# Karbone 0.1.4

Internal review build.

## Added

- API reference generated by Dokka from KDoc, published under `/api/` of the documentation site. Every public declaration is documented.

## Fixed

- The `User-Agent` header reported `karbone/0.1.0` regardless of the release; the version is now read from the jar manifest
  (`Implementation-Version`), `karbone/dev` when Karbone is not loaded from its jar.

## Documentation

- Rendering guide restructured around intent-oriented tables; templates, errors and testing pages link to the API reference instead of
  enumerating identifiers inline.
- The docs header shows the project name and the release version next to the brand mark.
