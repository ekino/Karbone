# Karbone logo

Carbon fiber weave (2x2 twill, two fiber gradients) on a rounded tile, with a geometric K drawn as strokes so no font is needed.

- `karbone-mark.svg` — the tile alone, any size from 32 px up.
- `karbone-favicon.svg` — coarser weave and heavier K for 16-32 px; also inlined as a data URI in `docs/_setup.qd`.
- `karbone-wordmark.svg` / `karbone-wordmark-dark.svg` — tile + "Karbone" in Space Grotesk 700 (falls back to Helvetica/Arial).

Colors: carbon black `#0e0e0e`, bone white `#f4f1ec`, ink `#1c1b1a`.
